Do not put the maintainer's first name into CLAUDE.md, tickets, docs, memory or commit messages. Write "the user" (or "the maintainer" where "the user" would be confused with users of the app), and avoid gendered pronouns.

**Why:** Explicit request on 2026-11-08 after the first CLAUDE.md draft used the name throughout.
**How to apply:** Check new text for the name before writing; in product docs, "user" means a shellight user, so prefer "the maintainer" there. Related: [[product-vision]].
